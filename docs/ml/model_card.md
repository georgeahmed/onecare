# Safety Gate Model Card

_Last updated: 2025-10-21_

## Overview
The Safety Gate service combines a classifier, NER model, and acuity heuristic to triage patient narratives. This model card documents the current production assets, evaluation metrics, and reproducibility knobs.

| Component   | Version / Source                | Checksum / Notes                                           |
|-------------|---------------------------------|------------------------------------------------------------|
| Classifier  | local-classifier-v3             | Bundled UUID: `classifier/local-classifier-v3.pt` (sha256 TBD) |
| NER         | local-ner-v2 (stub)             | Deterministic stub (no external download)                  |
| Acuity      | Stub heuristic (v1)             | No external weights                                        |

### Evaluation Snapshot
Metrics generated by `services-py/safety_gate_service/eval/run_eval.py`:

- Decision accuracy: ≥0.95 on golden set
- DIVERTED recall: ≥0.90 (guardrail enforced in CI)
- Temperature scaling: see `artifacts/eval/safety_gate_metrics.json`

### Datasets
- Golden set: `services-py/safety_gate_service/data/golden_set.v1.jsonl` (see manifest for checksum).
- Labeling guidance: `docs/ml/safety_gate_labeling.md`.

### Reproducibility
- Global seed: `SAFETY_GATE_SEED` (default `1337`) ensures deterministic behaviour across Python, NumPy, and Torch.
- Dependencies pinned in `services-py/pyproject.toml`.
- Evaluations sort records by ID and produce JSON artefacts for CI review.

### Intended Use & Limitations
- Designed for English narratives; multilingual support is best-effort via heuristics.
- Not a diagnostic tool; output informs triage workflows under human oversight.
