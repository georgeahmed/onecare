Task Index

Purpose
- Central index of all Task Cards sized for single AI runs, grouped by department. Each item links to a detailed card with context, files, steps, acceptance criteria, validation, and a status update command.

How To Run
- One task at a time: `make engineer-loop ENGINEER=<team/path> TASK='<task-id>' SCHEMAS=0 PY=0 RUNTIME=0 SMOKE=0`
- Example: `make engineer-loop ENGINEER=backend/engineer-01 TASK='BE-01.1'`
