Task: QA-01.16 — Flaky test detection and quarantine

Context
- Reduce CI noise by detecting flaky tests and quarantining while tracking fixes.

Files
- .github/workflows/ci.yml (matrix/rerun)
- docs/QA_FLAKES.md (new)

Steps
1) Add a CI job to rerun failed tests up to N times to flag flakiness; mark quarantined tests with a tag.
2) Track flake rate and owners; document a process for triage and closure.
3) Provide a local script to stress-run a test to reproduce flakiness.

Acceptance Criteria
- Flaky tests identified; re-run policy implemented; documentation in place.

Validate
