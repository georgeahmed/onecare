Task: DE-02.9 — Point‑in‑time join library (leakage‑safe training sets) + tests

Context
- Implement a leakage‑safe point‑in‑time join between labels/outcomes and features for model training.

Files
- scripts/feature_store/pit_join.ts or .py (new)
- services-py/tests/test_pit.py (new)

Steps
1) Given a label table with (entityId, event_time, label), join to feature PIT tables using `as_of` semantics (last feature snapshot before event_time).
2) Support window features (e.g., 7d counts) by precomputing aggregates or windowing during join.
3) Unit tests on synthetic timelines verifying no future leakage and correct joins across boundary cases.

Acceptance Criteria
- PIT joins correct; tests pass; interfaces documented for ML users.
