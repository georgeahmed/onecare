Task: DE-02.6 — Feature registry: entities, join keys, schema versioning (codegen + validators)

Context
- Establish a feature registry defining entities (e.g., patientId, practiceId), join keys, and versioned schemas for each feature set. Generate types and validators.

Files
- schemas/features/*.json (new)
- docs/FEATURE_REGISTRY.md (new)
- packages/events/src/contracts/* (generated) or separate package

Steps
1) Define entities and join keys; author JSON Schemas per feature group (e.g., triage_stats, access_window_stats), with `$id` and `additionalProperties: false`.
2) Add codegen to produce TS/Py types; compile validators for pipelines; document naming/versioning conventions.
3) Include feature metadata: description, freshness SLA, owner, sources, and privacy classification.

Acceptance Criteria
- Registry exists; schemas versioned; types/validators generated; documentation published.

Validate
- npm run codegen && npm run typecheck; peer review registry docs.

Status Update
- make engineer-done ENGINEER=data-engineering/engineer-02 TASK='DE-02.6' && make team-status-write
