Task: DE-01.11 — Data quality checks (constraints, domains, quarantine invalids; report)

Context
- Enforce data quality with deterministic checks; quarantine invalid records and report issues transparently.

Files
- scripts/dq/checks.ts or .py (new)
- docs/ANALYTICS_DQ.md (new)

Steps
1) Define constraints: required fields present; timestamp format and range; value domains per metric name; label keys allowed.
2) Implement DQ runner that scans recent partitions and writes invalid records to a quarantine bucket/table with reasons.
3) Emit a markdown/HTML report summarizing failures by type and rate; thresholds configurable.
4) Integrate DQ in CI for synthetic data and as a periodic job for real data (soft‑fail initially).

Acceptance Criteria
- Invalids quarantined; report generated; thresholds configurable; tests for constraint functions.

Validate
- Run DQ on a small test dataset; inspect quarantine and report.

Status Update
