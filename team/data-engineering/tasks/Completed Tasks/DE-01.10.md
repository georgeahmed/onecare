Task: DE-01.10 — Privacy & PHI minimization (labels allowlist, redaction, PII guardrails)

Context
- Ensure analytics payloads remain PHI/PII‑free. Enforce an allowlist of label keys and redact sensitive patterns before persisting.

Files
- analytics consumer module
- docs/CONVENTIONS.md (data handling)

Steps
1) Define a label allowlist (e.g., topic, service, outcomeCode, status) and reject/strip unknown/sensitive keys; document the list.
2) Redact values matching sensitive patterns (tokens, IDs, emails, phone numbers) using conservative regex and length caps.
3) Add unit tests with synthetic payloads containing PHI to ensure redaction/removal occurs; never store raw narratives.

Acceptance Criteria
- Sink receives only allowed/safe labels; tests pass; logs do not contain PHI.

Validate
- npm run test; inspect a sample redaction run.

Status Update
- make engineer-done ENGINEER=data-engineering/engineer-01 TASK='DE-01.10' && make team-status-write
