Task: DE-01.7 — Contract-first analytics models (schema versioning, codegen, compiled validators)

Context
- Enforce schemas-first for analytics metric events and derived rollup artifacts; keep schemas versioned and generate TS/Py types. Use compiled validators in the pipeline.

Files
- schemas/analytics/metric.json (source of truth)
- packages/events/src/contracts/* (generated TS)
- services-py/common/contracts (optional Py models)
- scripts/codegen/generate.js

Steps
1) Review `schemas/analytics/metric.json` for strictness (additionalProperties: false; formats); bump `$id` on breaking changes.
2) Run `npm run codegen` (and `RUN_PY=1` if Py models are used) to regenerate types; import them in consumers and validators.
3) Compile validators once on startup for high‑throughput ingestion (Ajv or fast‑json‑stringify path).
4) Add contract tests: valid and invalid examples; ensure invalids are rejected before sink writes.

Acceptance Criteria
- Types/validators current; invalid metrics rejected safely; tests pass.

Validate
- npm run codegen && npm run typecheck && npm test

Status Update
- make engineer-done ENGINEER=data-engineering/engineer-01 TASK='DE-01.7' && make team-status-write
