Task: DE-02.14 — Backfill/recompute framework (range runs, job metadata, idempotent writes)

Context
- Provide a robust backfill framework for recomputing feature views over historical data with job metadata tracking.

Current State
- `scripts/feature_backfill.js` writes JSONL snapshots but stores no job metadata, has no resume/dry-run, and only targets the in-memory store.

Files
- scripts/feature_backfill.js (extend)
- scripts/feature_store/backfill-ledger.jsonl (generated)
- docs/FEATURE_BACKFILL.md (new)

Steps
1) Turn the script into a reusable CLI that supports date-range selection, parallelism, dry-run, and a ledger recording run id, partitions processed, counts, and outcomes.
2) Ensure writes are idempotent across online/offline stores (use registry TTL + partition planner) and allow resume from ledger checkpoints.
3) Document operational safeguards, rollback strategy, and handoff expectations in the backfill guide.

Acceptance Criteria
- Backfill reliable and documented; idempotent; resumable.

Validate
- Synthetic backfill on small dataset; inspect outputs and ledger.
