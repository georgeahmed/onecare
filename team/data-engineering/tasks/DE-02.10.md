Task: DE-02.10 — Streaming ingestion (events→features) with idempotency, retries+jitter, DLQ

Context
- Ingest relevant events (e.g., triage outcomes, booking.created) and update feature sets reliably.

Files
- packages/bus/* (consumer)
- scripts/feature_store/ingest_stream.ts or .py (new)

Steps
1) Subscribe to chosen topics; map envelopes to feature mutations; propagate `correlationId`.
2) Enforce idempotency using natural keys; reserve before write to avoid double updates; annotate attempts with backoff.
3) Retries for transient errors; DLQ with minimal context for poison messages.
4) Metrics: ingest success/error/retry/DLQ; freshness lag per feature.

Acceptance Criteria
- Reliable streaming ingest; idempotent updates; metrics present.

Validate
- Unit tests with fakes; playback harness to simulate event streams.
