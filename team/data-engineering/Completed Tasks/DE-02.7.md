Task: DE-02.7 — Offline store layout (Parquet/Delta): partitioning, PIT tables, schema evolution

Context
- Design the offline store for scalable training and analytics: Parquet/Delta layout with partitioning, point‑in‑time (PIT) tables, and schema evolution.

Files
- docs/adr/2025-..-feature-offline-store.md (new)
- scripts/feature_store/offline_layout.ts or .py (new)

Steps
1) Choose Parquet/Delta; partition by `entity` and `date` (event_time truncated); document folder layout and manifest.
2) Create PIT tables with `effective_from`/`effective_to` intervals per entity row to enable as‑of joins.
3) Define schema evolution policy (additive fields only; backfill strategy); implement compaction routine.
4) Unit tests for write/read roundtrip, partition pruning, and PIT selection correctness on small synthetic data.

Acceptance Criteria
- ADR recorded; layout/rules documented; PIT correctness tests pass.

Validate
- Run a synthetic write/read/PIT selection demo.
