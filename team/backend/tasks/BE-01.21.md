Task: BE-01.21 — Performance baselines and budgets (p50/p95 latency, throughput)

Context
- Establish measurable performance targets and guardrails. Capture baseline latencies and throughput under realistic load; document and enforce time budgets per state.

Files
- apps/orchestrator/src/index.ts
- Makefile (add `make perf-orchestrator`)
- scripts/perf/orchestrator.sh (new)
 - docs/TEAM_STATUS.md (record baseline)

Steps
1) Add a perf script using `autocannon` (or similar) to drive `/safety-check` with small payloads; vary concurrency (1, 10, 50, 100).
2) Record p50/p95 latencies and throughput; capture CPU and memory profiles where possible.
3) Document time budgets per state (Normalize, SafetyGate, Publish, Audit) and ensure they sum under the total request budget.
4) Add a regression guard: fail perf job if p95 exceeds a configured threshold in CI (optional initially, warn-only).
5) Document how to run and interpret results; include tuning tips (concurrency limits, CB thresholds).

Acceptance Criteria
- Script runs locally and outputs clear stats; baseline numbers captured in README or ADR.
- Time budgets documented and aligned with Algorithm.md guidance.

Validate
- Run perf script; confirm results are stable across runs at reasonable variance.
 - Capture baseline numbers in TEAM_STATUS and set initial SLO targets.
