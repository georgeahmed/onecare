Task: BE-01.14 — Backpressure + time budgets

Context
- Prevent overload and enforce predictable latency via global/per-state concurrency caps and time budgets with graceful degradation.

Files
- apps/orchestrator/src/application/guard.ts (new)
- apps/orchestrator/src/index.ts
- packages/config/src/index.ts

Steps
1) Implement a lightweight semaphore for global concurrency and per-state limits; expose via config floors/ceilings. Use fair queueing (FIFO) with bounded length.
2) On saturation, return 429/503 with `Retry-After` and a consistent `over_capacity` error envelope; never queue unbounded.
3) Enforce time budgets per state and end-to-end; abort long-running operations with controlled failures. Record `budget.remaining_ms` in logs.
4) Emit metrics: current concurrency, `backpressure.queue`, `backpressure.wait_ms`, rejected count, and budget breaches; include correlationId in logs.
5) Degrade gracefully when CB is open or budget low: apply rules fallback (config) or deny with explanation; honor idempotency keys in degrade path.

Acceptance Criteria
- Load test shows bounded concurrency; saturation yields 429/503 with envelopes.
- Budget breaches abort with controlled failure without resource leaks.

Validate
- Simulate high concurrency; observe caps and correct responses.
- npm run typecheck && npm run test
