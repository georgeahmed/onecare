Task: BE-06.3 — ShapeCapacity micro-release (bounded, audited)

Context
- Release a bounded fraction of held-back slots when short-horizon forecasted need > supply (Algorithm.md 6.1), honoring guardrails and producing an audit trail.

Files
- apps/capacity/src/application/capacity.state.ts
- apps/capacity/src/application/forecast.ts (new)
- @onecare/config (hold_back_fraction, release_max_fraction, thresholds)

Steps
1) Add telemetry inputs (stubbed): arrivals/hr, queue depth, no-show rate, staffing level. Provide a `TelemetrySource` abstraction (see BE-06.5).
2) Implement a simple short-horizon forecast stub `forecastNeedVsSupply(t)` returning delta with confidence band.

5) Unit tests: trigger/no-trigger thresholds; dry-run produces audit only; bounded release never exceeds ceilings.

Acceptance Criteria

- No PHI in audit; typecheck/tests pass; no network in unit tests.
