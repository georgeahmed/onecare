Task: BE-01.1 — Add zero-trust gate (verify/auth/consent) plumbing

Context
- Enforce zero-trust at orchestrator ingress per Algorithm.md 1) System Orchestrator.

Files
- apps/orchestrator/src/index.ts
- packages/security/src/index.ts (types already present)
- docs/ERRORS.md (for error envelope style)

Steps
1) In /safety-check handler, extract auth header(s) and correlationId.
2) Call verifySignatureAndReplayGuard(auth, requestId). If false → 403 error envelope.
3) Call authorize(actor, action='submit', patientId, scope). If false → 403.
4) Call checkConsent(patientId, purpose='care', requestedResources=['QuestionnaireResponse','Communication']). If false → 403.
5) Short-circuit on denial; else continue to safety analysis.
6) Ensure all denials publish audit.event with correlationId.

Acceptance Criteria
- Missing/invalid auth returns 403 with error envelope (docs/ERRORS.md).
- Denials are logged and audit event is emitted (stubbed ok).
- Typecheck passes.
