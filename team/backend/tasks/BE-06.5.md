Task: BE-06.5 — Capacity telemetry adapter (pluggable, health-aware)

Context
- Abstract telemetry sources for ShapeCapacity decisions with a pluggable interface, basic health checks, and local caching. Keep tests deterministic with stubbed data.

Files
- apps/capacity/src/application/capacity.state.ts
- apps/capacity/src/application/telemetry.ts (new)

Steps
1) Define `TelemetrySource` interface: `getArrivalsPerHour()`, `getQueueDepth()`, `getNoShowRate()`, `getStaffingLevel()`, and optional `health()`.
2) Implement an in-memory stub source with configurable values + variance; add a simple TTL cache in the adapter.
3) Inject the source into capacity state; on unhealthy source, degrade gracefully (skip release) and emit a metric.
4) Add unit tests covering normal values, outliers, and unhealthy states; assert decisions reflect guardrails.

Acceptance Criteria
- Pluggable telemetry with health; graceful degradation on unhealthy.
- Deterministic tests; no network I/O; typecheck/tests pass.
