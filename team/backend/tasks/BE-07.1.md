Task: BE-07.1 — Clinician API: List tasks endpoint

Context
- Provide GET /clinician/tasks to power the dashboard queue with filters and pagination.

Steps
1) Define handler GET /clinician/tasks with query params: clinicId (required), priority, status, assignee, from, to, limit, cursor.
2) Return { items: TaskSummary[], nextCursor? } matching schemas/clinician/task-summary.json.
3) Enforce clinic scoping (RBAC); log correlationId; return error envelopes per docs/ERRORS.md.

Acceptance Criteria
- Valid filters return filtered list; pagination via limit+cursor; 200 w/ items.
- Invalid input → 400 invalid_input; missing auth → 401/403.
- Correlation id returned in header.

Validate
- Unit tests for filtering and pagination; contract tests against schema.
