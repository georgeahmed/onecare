Context

- apps/orchestrator/src/index.ts
- apps/orchestrator/README.md (update)
 - docker-compose.yml (optional healthcheck)

Steps

2) Add `/readyz` (readiness) checking: event bus connectivity (if applicable), critical circuit breaker states, idempotency store reachability, and a quick audit write dry-run. Return 503 when not ready.

5) Document probe endpoints and recommended k8s probe config in README and add Docker healthcheck (optional).

Acceptance Criteria
- Liveness/readiness endpoints behave correctly; orchestrator drains on shutdown within timeout.
- Unit tests for readiness logic (mock dependencies) and shutdown sequence.
