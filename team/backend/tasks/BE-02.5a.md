Task: BE-02.5a — Connection resilience (reconnect jitter, backoff, status events)

Context
- Make the NATS adapter resilient to disconnects with jittered reconnect/backoff and useful status events.

Files
- packages/bus/src/nats.ts
- apps/orchestrator/src/index.ts (consume status events later)

Steps
1) Implement reconnect strategy with exponential backoff and jitter; cap maximum backoff.
2) Emit status events (connected, disconnected, reconnecting, reconnected) with counters and timestamps.
3) Provide hooks or event emitter for services to subscribe to status changes (for readiness checks and logs).

Acceptance Criteria
- Disconnect/reconnect cycles do not crash the process; status events emitted; backoff bounded.

Validate
- Simulate intermittent NATS availability; observe reconnect behavior and status logs.
