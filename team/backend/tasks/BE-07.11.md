Task: BE-07.11 — Backpressure and concurrency control (ICS Hub)

Context
- Avoid overload by capping inflight messages and applying graceful backpressure when downstreams are slow.

Files
- apps/ics-hub/src/index.ts (consumer loop)
- apps/ics-hub/src/application/ics.state.ts

Steps
1) Add a small semaphore to limit concurrent message handling to N (configurable).
2) If queue grows beyond a threshold, emit warning metrics and optionally slow intake (sleep/yield) to avoid contention.
3) Enforce per-message time budgets; if exceeded, short-circuit with a safe failure Decision and send to DLQ if needed.

Acceptance Criteria
- Under load, inflight stays below configured cap; no crashes; DLQ used when budgets are exceeded.

Validate
- Load-test locally (fake messages) and observe metrics/logs.
