Task: BE-01.5a — Error codes/types from schema + envelope helper

Context
- Ensure error taxonomy is contract-first: derive codes from `schemas/common/error-envelope.json` and expose a typed helper for consistent envelopes.

Files
- schemas/common/error-envelope.json (existing)
- packages/events/src/contracts/error-envelope.ts (generated)
- apps/orchestrator/src/application/error.ts (new)

Steps
1) Re-export `ErrorEnvelope` and the union of `error.code` as `ErrorCode` from a local module for easy reuse.
2) Implement `errorEnvelope(code: ErrorCode, message: string, details?: Record<string, unknown>, correlationId?: string): ErrorEnvelope` with safe defaults (no stacks or secrets).
3) Add small utilities: `withCorrelationId(res, id)` to set/echo the header; and `safeMessage(code)` for stock messages.

Acceptance Criteria
- Codes strictly match schema; TS union available app-wide.
- Helper returns envelopes that validate against schema.

Validate
- Lightweight unit test to assert code strings and schema shape.
