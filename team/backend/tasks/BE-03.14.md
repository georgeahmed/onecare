Task: BE-03.14 — Health/readiness for triage service

Context
- Expose `/healthz` and `/readyz` with dependency checks (bus, FHIR repo) and implement graceful shutdown semantics.

Files
- apps/triage/src/index.ts
- docs/USAGE.md (probes configuration)

Steps
1) Add `/healthz` (always 200) and `/readyz` (200 only when dependencies healthy: bus connected, repo reachable, internal queues below thresholds).
2) Cache readiness probe result for a short TTL to avoid thrash.
3) Handle SIGTERM/SIGINT: stop consuming, drain in-flight work with grace period, close ports, exit.
4) Document recommended probe settings and shutdown expectations.

Acceptance Criteria
- Probes reflect health accurately; service drains gracefully.

Validate
- Simulate dependency loss and observe `/readyz` → 503; restore → 200. Trigger shutdown during load and verify graceful behavior.
