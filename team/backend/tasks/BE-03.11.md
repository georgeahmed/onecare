Task: BE-03.11 — Security & privacy (PHI minimization)

Context
- Align triage service with privacy-by-design: never log PHI; publish minimal payloads; enforce consent at boundaries.

Files
- apps/triage/src/index.ts
- packages/observability/src/logger.ts
- docs/EVENTS.md, docs/ERRORS.md, Algorithm.md (reference)

Steps
1) Define a logging allowlist (stable IDs, topic, decision, numeric score, priority) and redact everything else.
2) Ensure events omit narratives; publish only `patientId`, `taskId`, `priority`, and compact `reasons` codes. No raw text/attachments.
3) Before accessing patient context for assignment, check consent (via port/stub) and deny if not authorized; log denial safely and publish audit if applicable.
4) Add unit tests verifying redaction and event payload shapes.

Acceptance Criteria
- Logs/events are PHI-safe; consent checks enforced; tests pass.

Validate
- Inspect logs and emitted envelopes during a local dry-run.
