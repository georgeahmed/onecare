Task: BE-03.6 — Contract-first triage models and validators

Context
- Ensure schemas in `schemas/triage/*` are the source of truth. Generate types for TS/Python and compile validators for runtime checks at ingress and before publish.

Files
- schemas/triage/triage-input.json (existing)
- schemas/triage/triage-decision.json (new, to add)
- packages/events/src/contracts/* (generated TS)
- scripts/codegen/generate.js (reference)
- docs/EVENTS.md, docs/USAGE.md (reference)

Steps
1) Add `schemas/triage/triage-decision.json` capturing fields: `patientId`, `score`, `priority` (`STAT|URGENT|SOON|ROUTINE`), `reasons[]` (short codes), optional `duplicateOf`, `assignment` (owner/team id), and `features` (limited map). Default `additionalProperties: false` and use `format` where applicable.
2) Run `npm run codegen` to generate TS contracts; optionally `RUN_PY=1 npm run codegen` for Python models.
3) Wire validators: compile the JSON Schemas once on startup; at event ingress validate `TriageInput`; before publishing `tasks.created` or `triage.*` outputs, validate `TriageDecision`.
4) Add contract tests that validate sample payloads (happy/failure paths) against the generated validators. Keep tests offline.
5) Document contract evolution rules and `$id` versioning for triage schemas; update docs/EVENTS.md examples.

Acceptance Criteria
- New `triage-decision` schema exists with coherent `$id` and strict typing; codegen produces up-to-date TS artifacts.
- Ingress and publish-time validators enforce schemas; invalid payloads fail fast with safe error envelopes.
- Contract tests pass locally.

Validate
- npm run codegen && npm run typecheck && npm test
