Task: ML-01.19 — Evaluation harness (per-class precision/recall/F1, ROC/PR, calibration)

Context
- Build a robust evaluation harness to quantify performance with per-class metrics, confusion matrices, ROC/PR curves, and probability calibration plots.

Files
- services-py/safety_gate_service/eval/* (new)
- services-py/tests/test_eval.py (new)

Steps
1) Implement evaluation utilities to compute per-class precision/recall/F1, confusion matrices, ROC/PR curves, and expected calibration error (ECE).
2) Add scripts/notebooks to run eval on the curated dev set and golden set; save metrics as JSON artifacts.
3) Define acceptance thresholds (e.g., minimum recall on emergency class) and fail CI if violated (soft-fail initially).
4) Snapshot baseline results and include in ADR; store plots as PNGs for docs.

Acceptance Criteria
- Eval harness runs offline; metrics/plots generated; thresholds documented; tests validate metric shapes.

Validate
- pytest for metric utilities; run eval script against samples.
