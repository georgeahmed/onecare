Task: ML-01.12 — Performance: batching/quantization (optional), CPU/GPU toggle, memory caps

Context

Files
- services-py/safety_gate_service/ner.py
- services-py/safety_gate_service/classifier.py
- services-py/safety_gate_service/main.py

Steps
1) Add config flags: `ENABLE_BATCHING`, `BATCH_MAX_SIZE`, `DEVICE` (`cpu`/`cuda`), `ENABLE_QUANTIZATION`.
2) Implement a simple micro-batch aggregator for concurrent /analyze calls (bounded queue, short timeout) if enabled.
