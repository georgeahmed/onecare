Task: ML-01.22 — Adversarial input and toxicity guard

Context
- Harden the service against adversarial or toxic inputs: prompt injections, repeated characters, non-language noise, and abusive content.

Files
- services-py/safety_gate_service/main.py
- services-py/safety_gate_service/preprocess.py (new)

Steps
1) Add input sanity checks: length caps, character diversity heuristics, nonsense detection (e.g., very low alpha ratio), and reject/flag obviously invalid inputs with safe envelopes.
2) Optionally include a lightweight toxicity/abuse detector to avoid echoing harmful content in logs; always redact in logs.
3) Unit tests for guard behavior: adversarial strings, empty/noise inputs, and excessive length.

Acceptance Criteria
- Invalid inputs safely handled; logs PHI/abuse‑safe; tests pass.

Validate
- pytest -q services-py/tests
