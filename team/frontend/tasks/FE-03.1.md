Task: FE-03.1 — i18n library setup + locale switcher

Context

Files
- apps/portal/src/i18n/index.ts
- apps/portal/src/i18n/en.json
- apps/portal/src/components/LocaleSwitcher.tsx (new)

Steps

2) Externalize visible strings from Intake and error components into `en.json`.

Validate
