Task: FE-01.15 — Security & privacy (CSP, XSS/CSRF guardrails; no PII in logs)

Context
- Protect users and data on the client. Enforce strong CSP, sanitize/escape inputs/outputs, and avoid logging PII.

Files
- apps/portal/index.html (CSP meta or headers guidance)
- apps/portal/src/lib/security.ts (sanitizers)
- docs/CONVENTIONS.md (security)

Steps
1) Content Security Policy: no inline scripts/styles; allowlist domains; set `upgrade-insecure-requests` and `frame-ancestors 'none'`.
2) XSS: sanitize and escape any rendered rich content; avoid dangerouslySetInnerHTML; encode URLs.
3) CSRF: use same‑site cookies or tokens if cookies used; otherwise send `x-correlation-id` and avoid storing sensitive tokens.
4) Logging: redact headers/tokens; avoid PII in console; disable debug logs in production.

Acceptance Criteria
- CSP blocks inline; no XSS/CSRF anti‑patterns; logs PII‑free.

Validate
- Run CSP report‑only first; scan for violations; unit tests for sanitizer.
