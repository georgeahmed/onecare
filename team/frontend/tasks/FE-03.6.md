Task: FE-03.6 — RTL & bidirectional text support

Context
- Ensure the portal renders correctly for right‑to‑left languages and mixed‑direction content.

Files
- apps/portal/src/i18n/*
- apps/portal/src/styles/*

Steps
1) Set `dir` at html/root based on locale; add a runtime listener to update on switch.
2) Replace directional CSS with logical properties (margin‑inline, padding‑inline, inset‑inline) and avoid absolute left/right where possible.
3) Add `bdi` or CSS `unicode-bidi: isolate` where user content is injected to prevent direction leaks.
4) Verify icons/arrows/motion mirror appropriately or remain neutral.

Acceptance Criteria
- Layout mirrors correctly; no text direction artifacts; icons/affordances make sense in RTL.

Validate
- Switch to an RTL pseudo‑locale; manual checks on core screens; unit snapshot for CSS class toggles.
