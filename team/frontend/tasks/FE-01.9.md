Task: FE-01.9 — Design System + Design Tokens (themes, dark/high-contrast)

Context
- Create a consistent, scalable visual system using tokens (colors, spacing, typography, radii, motion) with support for dark and high‑contrast themes.

Files
- apps/portal/src/styles/tokens.css (new)
- apps/portal/src/components/ui/* (new)
- docs/USAGE.md (theming guide)

Steps
1) Define CSS variables for tokens: color palette with semantic roles, spacing scale, font sizes/line heights, radii, motion durations.
2) Implement theme toggles (dark/high-contrast) using class or media queries; persist preference; respect OS settings.
3) Build core UI primitives (Button, Input, Select, TextArea, Alert, Modal) using tokens; ensure a11y.
4) Document usage and Do/Don’t examples; keep components stateless and composable.

Acceptance Criteria
- Tokens and themes wired; components consume tokens; toggles work; documentation added.

Validate
- Visual check in dev; snapshot tests for components.
