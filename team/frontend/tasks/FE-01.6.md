Task: FE-01.6 — Loading/disabled states + retry/backoff for network errors

Context
- Improve UX under load and errors: prevent duplicate submits, show progress, and support bounded retries with backoff for 429/503.

Files
- apps/portal/src/components/SubmitButton.tsx (new)
- apps/portal/src/components/IntakeForm.tsx (wire states)
- apps/portal/src/lib/api.ts (retry/backoff helper)

Steps
1) Disable submit during in-flight requests; show a spinner and keep focus management accessible.
2) Implement a small `retryFetch(fn, { maxRetries: 2, baseDelayMs: 250, jitter: true })` for 429/503 only.
3) On retries, show an unobtrusive message and a cancel option; never retry on 4xx validation errors.

Acceptance Criteria
- No double submissions; backoff with jitter is applied only for 429/503; cancellation works.
- A11y maintained (focus, announcements); no PHI leaks in UI/logs.

Validate
- Manual: simulate 429/503 and verify bounded retries and messages; confirm immediate failure for 4xx.
