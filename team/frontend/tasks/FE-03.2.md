Task: FE-03.2 — Language preference capture (patient.locale) in submission

Context
- Capture and include the patient’s preferred locale in the `PortalSubmission` to improve downstream UX.

Files
- apps/portal/src/pages/Intake.tsx
- schemas/ingest/portal-submission.json (reference)

Steps
1) Add a `patient.locale` field to the Intake form bound to the i18n current locale; allow override via dropdown.
2) On submit, include `patient.locale` in the posted `PortalSubmission` (if allowed by schema; else open an issue to add it and run codegen).
3) Ensure value validation/sanitization (allowed locale codes only); do not log PII.

Acceptance Criteria
- Submission includes an allowed locale code when provided; invalid codes rejected client-side.

Validate
- Unit test mapping of locale selection to submission payload; invalid inputs rejected.
