Task: FE-01.11 — Form UX excellence (inline validation, error summary, autosave drafts)

Context
- Make the intake form fast, forgiving, and clear. Provide instant feedback, helpful error summaries, and autosave to prevent data loss.

Files
- apps/portal/src/components/form/* (new)
- schemas/ingest/portal-submission.json (reference)

Steps
1) Inline validation: validate on blur and submit; show concise inline messages near fields; aria-describedby wiring.
2) Error summary banner at top linking to each field; focus on submit failure; respect screen readers.
3) Autosave: save drafts to localStorage every few seconds; restore on revisit; show subtle saved indicator; clear on successful submit.
4) Input polish: masks/placeholders for dates; character counters; tooltip help and examples; device‑specific keyboards.

Acceptance Criteria
- Validation and error flows intuitive; drafts recoverable; a11y preserved; tests for validation mapping.

Validate
- Manual test; unit tests for validation mapping and autosave/restore.
