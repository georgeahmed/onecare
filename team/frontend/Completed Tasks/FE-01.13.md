Task: FE-01.13 — Performance budgets (Core Web Vitals: LCP/INP/CLS) and asset optimization

Context
- Make the portal feel instant. Set budgets for LCP/INP/CLS and optimize assets (images, fonts, JS) and routing.

Files
- apps/portal/vite.config.ts or webpack config (reference)
- apps/portal/src/* (lazy routes/components)
- docs/USAGE.md (perf guide)

Steps
1) Define budgets: LCP < 2.5s (mid‑tier device/network), INP < 200ms, CLS < 0.1. Track in dev with a lightweight RUM snippet.
2) Optimize: code split routes/forms; lazy‑load noncritical components; prefetch next step resources; compress images; use font‑display: swap.
3) Reduce JS: prefer native features; avoid heavy polyfills; memoize hot paths; remove dead weight.
4) Skeletons over spinners; optimistic UI where safe; subtle transitions.

Acceptance Criteria
- Dev RUM shows budgets met on local throttles; bundle size reduced; lazy routes verified.

Validate
- Lighthouse (local) and synthetic throttling; review bundle analyzer.
