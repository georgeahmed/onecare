Task: FE-01.3 — Error envelope renderer per docs/ERRORS.md

Context
- Render HTTP error envelopes consistently using the taxonomy in `docs/ERRORS.md`. Surface correlationId and helpful, localized messages without exposing internals.

Files
- apps/portal/src/components/ErrorAlert.tsx (new)
- docs/ERRORS.md (reference)

Steps
1) Create an `ErrorAlert` component that accepts an error envelope shape `{ error: { code, message }, correlationId? }`.
2) Map `error.code` to friendly copy; show `correlationId` for support; hide technical details by default.
3) Ensure accessible markup: role="alert", focus management, and link to retry/help actions.

Acceptance Criteria
- Given sample envelopes for 400, 403, 429, 503, renders correct copy and shows correlationId when present.
- Component has no PHI/PII; a11y checks pass.

Validate
- Component tests using sample envelopes; manual check in a dev view.
