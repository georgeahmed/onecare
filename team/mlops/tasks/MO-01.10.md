Task: MO-01.10 — GPU/CPU scheduling & resource classes

Context
- Ensure pods land on the right nodes (GPU vs CPU), with correct resource requests/limits and scheduling constraints.

Files
- infra/k8s/deployments/*.yaml
- docs/MLOPS_RESOURCES.md (new)

Steps
1) Define node selectors/taints/tolerations for GPU nodes; request `nvidia.com/gpu` resources when needed.
2) Set appropriate CPU/memory requests/limits; add memory/cuda env caps; use topology‑aware scheduling if available.
3) Document environment profiles (CPU‑only, GPU light, GPU heavy) and expected performance.

Acceptance Criteria
- GPU services schedule correctly; resource profiles documented.

Validate
- Deploy to a cluster with labeled nodes (or simulate); verify scheduling.
