Task: MO-01.12 — Shadow evaluation harness

Context
- Compare responses from vNext and vCurrent under real traffic (shadowing) and compute diffs/metrics against a golden set when available.

Files
- services-py/safety_gate_service/shadow_eval.py (new)
- docs/MLOPS_SHADOW.md (new)

Steps
1) Mirror a fraction of requests to vNext; capture outputs and latency without affecting user responses.
2) Compute agreement rate, distribution shifts, and latency deltas; log safe metrics and store samples for review.
3) Define accept/reject gates based on thresholds; document analysis process.

Acceptance Criteria
- Shadow runs produce metrics; decision gates documented; no user impact.

Validate
- Run a shadow trial in staging; review metrics and decide promotion.
