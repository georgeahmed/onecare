Task: MO-01.18 — Chaos/resiliency drills (kill pods, network faults)

Context
- Validate that services recover from common failures without breaching SLOs.

Files
- docs/MLOPS_CHAOS.md (new)

Steps
1) Define chaos scenarios: pod kill, node drain, network latency/packet loss to deps.
2) Run drills in staging; measure error rates and latency; ensure autoscaling/restarts recover quickly.
3) Document findings and remediation; schedule periodic drills.

Acceptance Criteria
- Drills executed; recovery within budgets; docs updated.

Validate
- Run a small drill; capture metrics and outcomes.
