Task: MO-01.14 — Container hardening (non-root, distroless, read-only FS, seccomp, capabilities)

Context
- Harden containers to reduce attack surface and enforce least privilege runtime settings.

Files
- services-py/*/Dockerfile
- infra/k8s/deployments/*.yaml
- docs/SECURITY.md (containers)

Steps
1) Use distroless or slim base images; run as non-root user; set read-only root filesystem; drop all Linux capabilities unless required.
2) Add seccomp/apparmor profiles; mount tmpfs for writable dirs if needed; avoid shell interpreters in base images.
3) Document testing steps and known exceptions.

Acceptance Criteria
- Dockerfiles updated; k8s securityContext set; docs present.

Validate
- Build images; deploy; verify no permission issues and scan baseline.
