Task: MO-01.9 — Autoscaling & concurrency (HPA/Knative)

Context
- Keep latency within SLOs by scaling pods with HPA or Knative and capping concurrency/time budgets per instance.

Files
- infra/k8s/hpa.yaml or charts values (new)
- docs/MLOPS_AUTOSCALING.md (new)

Steps
1) Configure HPA based on CPU/requests per second (custom metrics via Prometheus Adapter) with min/max replicas.
2) For Knative (optional), set `containerConcurrency`, scale-to-zero policy, and timeouts; document trade-offs (cold starts).
3) Implement per-pod max in-flight requests and request time budget; ensure readiness gates when saturated.

Acceptance Criteria
- Autoscaling configs applied; saturation protected; SLOs respected under load in staging.

Validate
- Load test; observe scale-out/in and latency behavior; adjust targets.
