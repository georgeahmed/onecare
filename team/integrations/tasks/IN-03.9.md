Task: IN-03.9 — Idempotency & dedupe (external calls and acks)

Context
- Prevent duplicate referrals and repeated ack handling using idempotency keys and a dedupe store.

Files
- apps/pharmacy-router/src/adapters/cpcs.client.ts
- apps/ics-hub/src/adapters/ics.client.ts
- packages/ports/src/idempotency.ts

Steps
1) Compute idempotency keys for CPCS referrals (practiceId + patientId + reasonCode + minute) and for ICS referral.request/ack using stable IDs.
2) Reserve-before-call semantics with TTL; on existing reservation, short-circuit with 409-equivalent result.
3) For acks, dedupe on `referralId + ackType` to avoid double-side effects.
4) Metrics: `idempotency.hit/miss`; logs include `correlationId` and safe IDs.

Acceptance Criteria
- Duplicate attempts suppressed; side effects occur once; metrics/logs present and safe.

Validate
- Concurrency tests for duplicate referrals/acks; exactly one proceeds.
