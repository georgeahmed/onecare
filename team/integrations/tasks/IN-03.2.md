Task: IN-03.2 — CPCS referral flow (timeouts/retries/jitter/CB; slotless fallback; error mapping)

Context
- Implement robust CPCS referral submission with timeouts, retries (exponential backoff + jitter), circuit breaker, and clear error mapping. Support slot and slotless paths per policy.

Files
- apps/pharmacy-router/src/adapters/cpcs.client.ts
- docs/CONVENTIONS.md (SSRF, redaction)

Steps
1) Implement `callWithGuard` wrapper in the adapter: 2s timeout default, max 2 retries with jitter, circuit breaker (open after N failures; half-open probe after TTL).
2) Map provider errors (HTTP/JSON) to internal codes: `invalid_input`, `forbidden`, `upstream_timeout`, `upstream_unavailable`, `conflict` (duplicate), `internal_error`.
3) Handle slotless fallback when configured: on slot unavailability, attempt slotless path; respect opt-in config and audit the reason.
4) Always propagate `x-correlation-id` and minimal headers; redact in logs.
5) Unit tests with fakes: timeout, 5xx, open CB, success; verify fallback path triggers when slot is unavailable.

Acceptance Criteria
- Retries and CB function as specified; errors mapped; fallback correct.
- Logs/metrics include correlationId and no secrets/PHI.

Validate
- npm run test
