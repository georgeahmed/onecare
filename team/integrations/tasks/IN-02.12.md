Task: IN-02.12 — API version/content negotiation (GP Connect headers; Accept/Prefer)

Context
- Ensure correct headers for GP Connect and FHIR JSON to avoid subtle failures and guarantee compatibility across provider versions.

Files
- apps/booking/src/adapters/gpconnect.client.ts
- packages/ports/src/fhir.ts (reference for FHIR JSON)

Steps
1) Set explicit `Accept: application/fhir+json` and `Content-Type: application/fhir+json; charset=utf-8`.
2) Include GP Connect–specific headers where applicable (configurable): interaction/trace identifiers (documented only, no hard dependency) and any gateway-required headers.
3) Validate response content-type and version hints where available; surface a typed error on mismatch.
4) Unit tests asserting headers on outbound requests and content-type checks on responses.

Acceptance Criteria
- Headers and content negotiation are correct; tests pass deterministically.
