Task: IN-03.3 — ICS referral/ack client (TLS/auth; route mapping; ack semantics)

Context
- Provide ICS HTTP client for referral.request and referral.ack with TLS and auth (creds), plus config-driven route mapping from org to endpoint.

Files
- apps/ics-hub/src/application/ics.state.ts (consumer)
- apps/ics-hub/src/adapters/ics.client.ts (new)

Steps
1) Define `sendReferral(req: IcsReferralRequest): Promise<IcsAck>` and `ack(refId: string, payload)`. Use generated types from schemas.
2) Support TLS and credential injection (API keys/JWT); never log secrets. Read endpoints and creds from config.
3) Implement org→endpoint mapping (allowlist) and per-org rate limit stubs.
4) Implement timeouts, retries with jitter, and circuit breaker (same guard as CPCS) with correlationId propagation.
5) Unit tests with fakes: success, timeout, invalid org (blocked), 5xx, CB open; assert ack semantics and mapping.

Acceptance Criteria
- TLS/auth supported; mapping enforced; guardrails active; types align with schemas.

Validate
- npm run build && npm run typecheck && npm test
