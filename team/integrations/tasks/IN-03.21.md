Task: IN-03.21 — Billing contracts & validators (Claim/Response schemas; codegen; DLQ)

Context
- If billing is used, define Claim/Response schemas contract-first, generate types, validate rigorously, and ensure reliable publish with DLQ.

Files
- schemas/billing/claim.json, schemas/billing/response.json (new)
- packages/events/src/contracts/* (generated)
- apps/ics-hub/src/adapters/billing.client.ts (optional)

Steps
1) Add minimal, strict Claim/Response schemas (stable IDs, amounts, codes; no PHI) with `$id` and `additionalProperties: false`.
2) Run codegen; compile validators and enforce on publish/ingress.
3) Implement reliable publish (timeouts/retries/CB) and DLQ fallback on failure, following bus policies.
4) Contract tests (valid/invalid); no network.

Acceptance Criteria
- Schemas and validators in place; reliable publish with DLQ; tests pass.

Validate
- npm run codegen && npm run typecheck && npm test
