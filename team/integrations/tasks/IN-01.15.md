Task: IN-01.15 — OIDC JWT verify with JWKs rotation (kid/aud/iss/nbf/exp; skew)

Context
- Implement robust JWT verification for NHS Login (or OIDC provider) with JWKs caching and rotation, enforcing claims and accounting for clock skew.

Files
- packages/security/src/index.ts
- apps/* (consumers later)

Steps
1) Implement JWKS retrieval with caching and background refresh; select key by `kid`; support rotation by re-fetch on unknown `kid`.
2) Verify JWT signature and validate `iss`, `aud`, `exp`, `nbf`, and `iat` with a configurable ±skew (e.g., 60s); reject if any validation fails with a typed error.
3) Expose a `verifyToken(token)` function that returns a typed identity context (subject, scopes) on success, no PII; redact tokens in logs.
4) Unit tests for valid token, expired token, skew tolerance, and key rotation.

Acceptance Criteria
- JWT verification robust with claim checks and rotation; tests pass.

Validate
- npm run test
