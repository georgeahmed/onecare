Task: TV-01.7 — Streaming ingest → Object Store (Binary/DocumentReference)

Context
- Stream audio chunks to an Object Store and link via FHIR `Binary`/`DocumentReference`. Enforce TTL retention and PHI-safe handling.

Files
- apps/telephony/src/adapters/ivr.adapter.ts
- packages/ports/src/object-store.ts
- packages/ports/src/fhir.ts

Steps
1) Buffer/stream audio chunks to Object Store using `ObjectStore.put` with a stable key (callId + timestamp). Do not log raw audio or transcripts.
2) On call end, create a `DocumentReference` in FHIR referencing the stored `Binary` (or external URL). Include only necessary metadata; avoid PHI in log fields.
3) Enforce retention via TTL on Object Store keys (config-driven); add a cleanup/spooler note if immediate delete fails.
4) Metrics: `telephony.audio.chunks`, `telephony.audio.bytes`, `telephony.audio.upload_ms` histograms.
5) Unit tests with fakes ensuring linking behavior and TTL application.

Acceptance Criteria
- Audio stored with stable keys; FHIR link created; TTL enforced; logs contain no PHI.

Validate
- npm run test; inspect logs/metrics in a local stub.

Status Update
